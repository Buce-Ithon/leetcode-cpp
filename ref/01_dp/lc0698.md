# Analysis

It is a wonderful and beautiful journey to finish this problem. Let me introduce it.

There are some basic information must be mentioned: 
- The `sum` (of `nums[]`) should be divisible by `k`, and set `target = sum / k`.
- The maximum of `nums[]` cannot exceede `target`.

A simple approach is to visualize the problem as follows: `n` numbers in a `nums[]` array need to be placed into `k` buckets, with the sum of the numbers in each bucket equal to `target`. For each bucket, we can solve it using the simplest traversal approach: we simply need to start traversing from the first number in the `nums[]` array, adding each subsequent number to it, and repeating this process. This will build a tree of depth `n` (we can prune some branches by comparing the sum with the target during the process), resulting in a time complexity of $O(k^n)$.

But it's not fast enough. Could we have a more simple and fast method? Here it is. (The following idea is learned from [NeetCode](https://www.youtube.com/watch?v=mBk4I0X46oI))

Let's simplify the above approach with DP:
1. Keep the track of `k` buckets, but now, we don't initialize `k` buckets but `1` at beginning. Because for remaining `k-1` buckets, we could use the same method to consider and for them the used data in `nums[]` is less (after filling the first bucket), which reminds us to use backtrack algorithm.
2. For the first bucket, let's pick one element in `nums[]`, there are only 2 conditions:
   1. the element is in bucket (could be put into it);
   2. or the element cannot be put into the bucket (sum in the bucket may over `target`).
3. Then it's easy to do the same thing for rest elements in `nums[]`. After finish the first bucket, we could do the same process for the remaining `k-1` buckets with rest elements in `nums[]` (backtrack). So we could build a tree of depth `n` (but the time complexity of $O(2^n)$, more precisely $O(k * 2^n)$).

To represent the state of every elements in `nums[]` in the tree, we make an array `memo[]`: 
```cpp
        int n = static_cast<int>(nums.size());
        // memo[used_mask] stores whether the state (represented by bitmask) can lead to a valid partition.
        // -1: unvisited, 0: false, 1: true
        std::vector<int> memo(1 << n, -1);
```

The out condition in backtrack is very easy relatively: 
```cpp
            // Base case: All k subsets have been successfully constructed
            if (k_remaining == 0) {
                return true;
            }

            // Return memoized result if already calculated
            if (memo[mask] != -1) {
                return memo[mask] == 1;
            }

            // If current bucket is filled, move to the next subset starting sum from 0
            if (current_sum == target) {
                bool res = backtrack(mask, 0, k_remaining - 1);
                memo[mask] = res ? 1 : 0;
                return res;
            }
```

DP process is also clear.

Besides, there are some optimal and C++ language features which are indispensible to introduce:

1. First sorting `num[]` by descending (`std::sort(nums.rbegin(), nums.rend())`), choose bigger numbers priorly, which allows illegal branched to bottom out and return to normal as early as possible, achieving significant pruning.
    ```cpp
            // Sort in descending order for greedy pruning
            std::sort(nums.rbegin(), nums.rend());
    ```
2. `std::vector::rbegin` and `std::vector::rend` are reversal iterators of `std::vector`.
3. `std::function` is used to declare and encapsulate a recursive lambda function (`backtrack`) locally within the `canPartitionKSubsets` method.
   1. Enabling Self-Referential Recursion in Lambdas
        When defining a recursive lambda, using `auto` leads to a compilation error because the compiler cannot deduce the type of `backtrack` while parsing its own body:

        ```cpp
        // Compilation Error: Cannot deduce type of 'backtrack' inside its own body
        auto backtrack = [&](int mask, int current_sum, int k_remaining) {
            // ...
            if (backtrack(mask | (1 << i), current_sum + nums[i], k_remaining)) { ... }
        };
        ```

        Explicitly typing the wrapper with `std::function<bool(int, int, int)>` defines the function signature beforehand. This allows the closure to safely capture and invoke `backtrack` recursively by reference.

   2. Encapsulation and Direct Context Capture
        Compared to declaring a private helper method on `Solution`, an internal lambda wrapped in `std::function`:
        * **Limits Scope**: Keeps the helper function strictly local to `canPartitionKSubsets` without exposing implementation details to the class interface.
        * **Simplifies State Capture**: Captures local variables (`target`, `nums`, `n`, `memo`) directly via `[&]`, eliminating the need to pass 5–6 extra arguments through every recursive frame.

# Code
```cpp
class Solution {
public:
    /**
     * @brief Determines if the array can be partitioned into k subsets with equal sum.
     * 
     * @param nums Vector of integers representing the elements.
     * @param k Number of equal sum subsets to form.
     * @return true If valid partition exists, false otherwise.
     */
    bool canPartitionKSubsets(std::vector<int>& nums, int k) {
        int total_sum = std::accumulate(nums.begin(), nums.end(), 0);

        // Basic impossibility check
        if (total_sum % k != 0) {
            return false;
        }

        int target = total_sum / k;

        // Sort in descending order for greedy pruning
        std::sort(nums.rbegin(), nums.rend());

        // If the largest single element exceeds the target sum, partition is impossible
        if (nums[0] > target) {
            return false;
        }

        int n = static_cast<int>(nums.size());
        // memo[used_mask] stores whether the state (represented by bitmask) can lead to a valid partition.
        // -1: unvisited, 0: false, 1: true
        std::vector<int> memo(1 << n, -1);

        // Lambda helper for Backtracking with Bitmask DP State Memoization
        std::function<bool(int, int, int)> backtrack = [&](int mask, int current_sum, int k_remaining) -> bool {
            // Base case: All k subsets have been successfully constructed
            if (k_remaining == 0) {
                return true;
            }

            // Return memoized result if already calculated
            if (memo[mask] != -1) {
                return memo[mask] == 1;
            }

            // If current bucket is filled, move to the next subset starting sum from 0
            if (current_sum == target) {
                bool res = backtrack(mask, 0, k_remaining - 1);
                memo[mask] = res ? 1 : 0;
                return res;
            }

            // Try picking available elements
            for (int i = 0; i < n; ++i) {
                // If element i is already used, skip
                if ((mask & (1 << i)) != 0) {
                    continue;
                }

                // Pruning: if adding nums[i] exceeds target, skip
                if (current_sum + nums[i] > target) {
                    continue;
                }

                // Choose nums[i] and recurse
                if (backtrack(mask | (1 << i), current_sum + nums[i], k_remaining)) {
                    memo[mask] = 1;
                    return true;
                }
            }

            memo[mask] = 0;
            return false;
        };

        return backtrack(0, 0, k);
    }
};
```
