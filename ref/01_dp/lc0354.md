# Analysis

The main steps is shown below code piece. I'll note and review some vague points: 

In dp process: 

1. `tails[k]` stores the minimum value of the last element (height) among all increasing subsequences of length $k+1$.
    - If we encounter a height $h$ that is greater than all numbers in the current `tails` (`it == tails.end()`), it means we can append the current envelope to the end of the longest subsequence, increasing the subsequence length by $1$, so we execute `tails.push_back(h)`.
    - However, if $h$ is not the largest (`it != tails.end()`), lower_bound will find the first position greater than or equal to $h$ (let's say `*it`). In this case, executing `*it = h` means that since we've found a smaller ending $h$, it can replace the original larger ending `*it`, while maintaining the increasing property of the current length.
2. You don't need to mannually consider the same widths. Because before dp, we already use `std::sort()` to let the array `envelopes[]` be ascending by width and descending by height if widths are equal. It leads to that when we perform dp, we'll not choose 2 elements in amid descending subsequence, which means the rest same widths are omitted automatically. I think it's a indispensable point.

# Illustration

`std::lower_bound` (defined in `<algorithm>`) is used to utilize binary search to find the first element which is `>=` specified value in a sorted array.

- **Condition:** Find th first iterator that satisfies `element >= value` (or doesn't satisfy the customed comparison predicates `comp(element, value)`)
- **Return value:** 
  - If the satisfied element is found, return the iterator to the element.
  - If all `elements < value`, then return the iterator to the end (i.e., `last` / `.end()`).
- **Time complexity:**
  - For random access iterators (such as: `std::vector`, `std::deque`, native arrays): $O(log N)$ (Since pointer jump can perform directly).
  - For bidirectional iterators (such as: `std::list`): $O(log N)$ (comparison) + $O(N)$ (iterator remove) = $O(N)$

Examples: 
```cpp
std::vector<int> nums = {10, 20, 30, 30, 40, 50};

// Find the first element >= 30
auto it1 = std::lower_bound(nums.begin(), nums.end(), 30);
// *it1 is 30, point to the position of first 30 (index = 2)

// Find the first element >= 35
auto it2 = std::lower_bound(nums.begin(), nums.end(), 35);
// *it1 is 40, point to the position of first 40 (index = 4)

// Find the first element >= 60
auto it3 = std::lower_bound(nums.begin(), nums.end(), 60);
// it3 == nums.end()
```

Compare with `std::upper_bound`:

|Function | Condition | "Find 30 in {10, 20, 30, 30, 40} |
|:---:|:---:|:---:|
|std::lower_bound | the first ≥ val | return the iterator to first 30 (index = 2) |
|std::upper_bound | the first > val | return the iterator to first 40 (index = 4) |

# Code

```cpp
class Solution {
public:
    /**
     * @brief Find the maximum number of envelopes that can be nested
     *
     * @param envelopes Reference to a 2D vector where envelopes[i] = [width, height]
     * @return int The maximum number of nested envelopes
     */
    int maxEnvelopes(std::vector<std::vector<int>>& envelopes) {
        if (envelopes.empty()) {
            return 0;
        }

        // 1. Custom sort: Ascending by width; if widths are equal, descending by height
        std::sort(envelopes.begin(), envelopes.end(),
                  [](const std::vector<int>& a, const std::vector<int>& b) {
                      return a[0] == b[0] ? a[1] > b[1] : a[0] < b[0];
                  });

        // 2. Extract height array to perform Longest Increasing Subsequence (LIS) -DP
        // 3. Perform LIS using binary search (std::lower_bound) O(N log N)
        std::vector<int> tails;
        for (const auto& env : envelopes) {
            int h = env[1];
            auto it = std::lower_bound(tails.begin(), tails.end(), h);
            if (it == tails.end()) {
                tails.push_back(h);
            } else {
                *it = h;
            }
        }

        // 4. The length of tails is the max number of envelopes
        return static_cast<int>(tails.size());
    }
};
```
