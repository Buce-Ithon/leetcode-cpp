# Analysis

The whole analysis process is below the code piece comments.

But there are a special place you need to notice: 

For this main step of dynamic process: 
```cpp
        // 5. The process of DP
        for (int i = 0; i < n; i++) {
            for (int j = 0; j < i; j++) {
                if (nums[i] % nums[j] == 0 && dp[i] <= dp[j] + 1) {
                    dp[i] = dp[j] + 1;
                    prev[i] = j;
                }
            }
            if (dp[i] > dp[maxi]) maxi = i;
        }
```
You couldn't use: 
```cpp
        for (int i = 0; i < n; i++) {
            for (int j = 0; j < i; j++) {
                if (nums[i] % nums[j] == 0) {
                    dp[i] = std::max(dp[j] + 1, dp[i]);
                    prev[i] = j;
                }
            }
            if (dp[i] > dp[maxi]) maxi = i;
        }
```
Or to say, you first need to determine if `nums[i] % nums[j] == 0` and `dp[j] + 1 >= dp[i]` simultaneously, then you can update `dp[i]` and `prev[i]`. This will not infulent `dp[i]` (the length of LDS of the index `i` in current traverse circle), but may cover the `prev[i]` with a incorrect (likely leads to a shorter LDS indexs) previous index when `dp[j] + 1 <= dp[i]`, and it's dangerous and reminding.

# Code

```cpp
class Solution {
public:
    /**
     * @brief Find the largest subset of numbers where every pair is divisible
     *
     * @param nums Reference to a vector of distinct positive integers
     * @return std::vector<int> The largest divisible subset
     */
    std::vector<int> largestDivisibleSubset(std::vector<int>& nums) {
        // 1. Sort the input array for convenience of comparison and calculating
        std::sort(nums.begin(), nums.end());
        int n = static_cast<int>(nums.size());
        // 2. Create dp[n]: used to record the LDS of the current index in every traverse state
        std::vector<int> dp(n,1);
        // 3. Create prev[n]: used to record the index sequence of the LDS of the current index in every traverse state
        std::vector<int> prev(n,-1);
        // 4. Recording the final LDS of whole indexs
        int maxi = 0;
        // 5. The process of DP
        for (int i = 0; i < n; i++) {
            for (int j = 0; j < i; j++) {
                if (nums[i] % nums[j] == 0 && dp[i] <= dp[j] + 1) {
                    dp[i] = dp[j] + 1;
                    prev[i] = j;
                }
            }
            if (dp[i] > dp[maxi]) maxi = i;
        }
        // 6. Push back elements into the and according to the index recorded by prev[n]
        std::vector<int> ans;
        for (int i = maxi; i != -1; i = prev[i]) {
            ans.push_back(nums[i]);
        }
        std::reverse(ans.begin(), ans.end());
        return ans;
    }
};
```
