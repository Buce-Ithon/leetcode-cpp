# Analysis

It's a not much easy question for me (first encounter) and after watching some hints, it hits me that this is a rare and indispensable problem. So I ganna to take an overall and detailed analysis.

The core mechanism of this problem is: **Once you choose a value $x$, you must abandon all $x-1$ and $x+1$**. Although it cann't help me solving the problem directly, but it is the first step (also apparent) to achieve dp.

Let's explore more about the problem:

1. Stratify the data in array `nums[i]` by value: From "Value Selection" to "Contiguous Position Selection"

   - Step 1. Merge Identical Values: 
      If you decide to pick `x`, then it's inevitably to pick all instance of $x$ in array `nums[i]`. Because choosing the first `x` already eliminates all `x-1` and `x+1`, so picking the remaining `x`'s incurs no additional side effects - only pure profit.
      Therefore, the total points `x` bringing are:
      $$sum[x] = x \times (\text{frequency of } x \text{ in the original array})$$

   - Step 2. Map to the layers:
     We treat the unique numerical values as layer numbers (ranging from `0` to `max_val`):
     - Layer `x` contains points `sum[x]`.
     - **Constraint:** You cannot take adjacent layer (if you take `x`, you cannot take `x-1` and `x+1`).

2. Dynamic programming state transmition

    Define a 1D DP array where `dp[i]` represents the maximum points that can be earned considering values in the range $[0, i]$. For every value `i`, we only have 2 choices: 
      - **Do notp pick `i`:** The max points equals to the max points achievable from the first `i-1` values, which is `dp[i-1]`.
      - **Pick `i`:** We earn the points `sum[i]`, but since we couldn't choose `i-1`, we could only add the max points achievable from the first `i-2`, i.e., `dp[i-2]+sum[i]`.

    The state transmition equation:
    $$dp[i] = max(dp[i-1], dp[i-2]+sum[i])$$

3. Space Optimization (Rolling Variables)

    Since the calculation of $\text{dp}[i]$ only relies on the two immediately preceding states ($\text{dp}[i-1]$ and $\text{dp}[i-2]$), we do not need to maintain the full DP array. Instead, we can optimize the space by using two variables:

    *   `first` represents $\text{dp}[i-2]$
    *   `second` represents $\text{dp}[i-1]$

    In each iteration, we calculate `current = max(second, first + sum[i])`, and then update the rolling variables: `first = second` and `second = current`. 

    This space optimization reduces the auxiliary space complexity from $O(\text{max\_val})$ for the DP array down to $O(1)$ (excluding the pre-computed frequency array `sum`).

# Code
```cpp
class Solution {
public:
    /**
     * @brief Find the maximum number of points that can be earned
     *
     * @param nums Reference to a vector of integers
     * @return int Maximum total points
     */
    int deleteAndEarn(std::vector<int>& nums) {
        if (nums.empty()) {
            return 0;
        }

        // 1. Find the maximum element to bound the range of values
        int max_val = 0;
        for (int num : nums) {
            max_val = std::max(max_val, num);
        }

        // 2. Aggregate the total points earned by picking each value
        std::vector<int> sum(max_val + 1, 0);
        for (int num : nums) {
            sum[num] += num;
        }

        // 3. Dynamic Programming (equivalent to House Robber problem)
        //    dp[i][0]: Max points from values up to i without picking i
        //    dp[i][1]: Max points from values up to i while picking i
        int first = sum[0];
        int second = std::max(sum[0], sum[1]);

        for (int i = 2; i <= max_val; ++i) {
            int current = std::max(second, first + sum[i]);
            first = second;
            second = current;
        }

        return second;
    }
};
```
